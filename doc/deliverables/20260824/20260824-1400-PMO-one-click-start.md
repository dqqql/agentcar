# 前后端一键启动交付

## 结论区

- 新增根目录 `start-all.ps1`，一条命令同时启动 FastAPI 后端和 Vite 前端。
- 新增 `start-all.cmd`，支持直接双击或从 PowerShell 执行。
- 脚本自动检查 Python、Node、npm 和依赖；只在依赖缺失时安装，正常启动不重复安装。
- 服务就绪后自动打开 `http://127.0.0.1:5173`；按 `Ctrl+C` 会同时关闭前后端。
- 子进程隐藏运行，stdout/stderr 写入 `.dev-runtime/`，该目录已加入 `.gitignore`。

## 风险与约束区

- 8000 或 5173 端口被其他程序占用时，脚本会停止并提示，不会擅自结束未知进程。
- 直接关闭启动窗口不如 `Ctrl+C` 可控；建议始终按 `Ctrl+C` 退出。
- 后端一键测试模式不启用 `--reload`，修改 Python 代码后需要重启脚本。
